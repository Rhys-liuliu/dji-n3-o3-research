# Requirements

The reference is the actual behavior of Goggles 3 connected to O3, not an assumed feature list. That reference still needs to be inventoried on real devices.

| Area | Required result | Status |
| --- | --- | --- |
| RF | Direct pairing, stable link, reconnect | Not tested |
| Video | Live video with timing and display appropriate to N3 | Not tested |
| OSD | Reference link status and supported OSD functions | Not inventoried / not tested |
| Recording | Functions actually available in the G3 + O3 reference | Not inventoried / not tested |
| Settings | Reference camera and link settings | Not inventoried / not tested |
| Other reference functions | Inventory first, then assess individually | Unknown |
| O4 | Preserve existing O4 functionality | Not tested |
| Recovery | USB recovery after failed modified-firmware boot | Not demonstrated |

Constraints: no disassembly; USB analysis allowed; an O3 may be borrowed for validation. No modified-firmware flashing is currently authorized because the recovery prerequisite remains unmet. No requirement here establishes technical feasibility.
